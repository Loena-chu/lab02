# Lab 4: Numbers and Input Handling

## Overview
This lab demonstrates basic number operations, temperature conversion, string formatting, and input validation in Python.

## Program Description
The `lab4_numbers_input.py` script performs the following operations:

1. **Time Conversion**: Converts 3601 seconds into minutes and seconds
2. **Temperature Conversion**: Converts 23.0°C to Fahrenheit
3. **String Formatting**: Demonstrates formatted output with alignment
4. **Input Validation**: Prompts user for a voltage value (0-10) and validates the input

## Features
- Arithmetic operations with integers and floats
- Exception handling for invalid input
- Conditional validation of input range
- Formatted output using f-strings

## How to Run
1. Ensure you have Python installed
2. Navigate to the lab_04 directory
3. Run the script: `python lab4_numbers_input.py`
4. Enter a voltage value when prompted (must be between 0 and 10)

## Expected Output
```
3601 seconds is 60 minutes and 1 seconds
Celsius: 23.00 °C
Fahrenheit: 73.40 °F
         S1    2.500
Enter a voltage value between 0 and 10: 5.5
Voltage: 5.500 V
Scaled value: 16.500 units
```

## Learning Objectives
- Understand basic arithmetic operations in Python
- Learn input validation and exception handling
- Practice string formatting techniques
- Handle user input safely
